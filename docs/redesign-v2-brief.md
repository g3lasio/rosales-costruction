# Redesign V2 Brief

## Before-and-after plan

| Decision | Record |
|---|---|
| Mode | Redesign · Overhaul |
| Preserve | Rosales logo, real project photography, bilingual content, all routes, LeadPrime chat and form delivery, SEO/SSR and accessibility contracts. |

## Design decisions

**Design Read:** A premium local-contractor website for homeowners and commercial property owners evaluating a significant outdoor project. The visual language is **kinetic field-journal editorial**: an architectural project dossier with the movement and material clarity of an active worksite, not a generic contractor gallery.

| Dial | Level | Concrete consequence |
|---|---:|---|
| Visual variance | 8/10 | A stable fixed navigation spine frames asymmetric project bands, transformation panels, and material-led layouts. |
| Motion intensity | 6/10 | Reveal controls, image comparison, measured hover states, and short view transitions. Reduced-motion settings retain all information without animation. |
| Information density | 6/10 | The homepage uses project proof, process, service area, and conversion cues in distinct, easily scanned blocks. |
| Asset dependence | 9/10 | Only the approved logo and real Rosales work are used as brand imagery; no stock work is introduced. |
| Brand fidelity | 8/10 | The Rosales mark, evergreen/limestone palette, craftsmanship voice, licensing, routes, and service content remain intact. |

The signed same-site construction sequence in the original assets is used for the primary comparator: `198_WhatsApp-Image-2024-09-12-at-7.26.22-AM.webp` captures the prepared front approach, and `199_WhatsApp-Image-2024-09-12-at-7.26.23-AM.webp` captures the completed concrete path. The captions identify the actual visual stages and do not claim performance figures or dates not supplied by Rosales.
